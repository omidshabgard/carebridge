# CareBridge Frontend

React + TypeScript + Vite patient portal. Copy `.env.example` to `.env`, run `npm install`, then `npm run dev`. The API defaults to `http://localhost:3001/api`. Run `npm run build` to verify the production bundle.

The interface includes responsive navigation, care discovery, appointments, secure-message views, medications, results, records, billing, insurance, care team, documents, settings, search, and action feedback. Current records are synthetic UI fixtures and will be connected to the API during local integration.
